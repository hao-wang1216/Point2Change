## Logo generation prompt

Use case: logo-brand. Create a single polished app icon for Point2Change,
an open-source desktop tool converting point clicks into change masks in
bi-temporal satellite imagery. A distinctive minimal abstract geometric mark:
two slightly offset aerial-map tile silhouettes, a precise coral point/click,
and an emerald change-region polygon that visually emerges from the point.
Strong unified silhouette, professional scientific software identity, clean flat
vector-like rendering, dark navy outlines, teal/emerald accents, one coral point.
Generous negative space, centered square composition, legible at small size.
Transparent background, no enclosing background square. No text, no letters,
no numbers, no gradients, no 3D, no shadows, no satellite hardware, no Meta logo,
no watermark. Output only the finished icon.
