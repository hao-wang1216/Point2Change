# Model checkpoint

Download the original **SAM 2 Hiera Large** checkpoint separately:

[sam2_hiera_large.pt](https://dl.fbaipublicfiles.com/segment_anything_2/072824/sam2_hiera_large.pt)

Place it in this directory as `sam2_hiera_large.pt`, or set
`CHANGE_LABELER_MODEL` to its full path. The environment variable retains its
original name for compatibility. Use the original SAM 2 checkpoint, not SAM 2.1.
Model weights are excluded from Git and are not distributed in this repository.
